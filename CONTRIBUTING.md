# Contributing

Contributions are welcome. rust-proxy is dual-licensed (AGPL-3.0, or a paid
Commercial License) by Jeff Parrish PC Services LLC, so every code
contribution needs the short agreement in [CLA.md](CLA.md). You keep your
copyright; the agreement lets the LLC ship your work under both licenses.

## Code and documentation

1. Open an issue first for anything bigger than a small fix, so you don't
   spend time on something that won't fit.
2. Run `cargo test` and `cargo fmt` before sending a merge request. New
   behavior needs tests.
3. Put `I have read CLA.md and agree to it.` in the merge request
   description and sign off every commit (`git commit -s`). Merge requests
   without both are not reviewed.
4. Use descriptive commit messages that say what changed and why.

The [architecture notes](docs/architecture.md) map out the code.

## Bug reports and ideas

Issues are welcome, with the version, what you did, and what you expected.

## Security issues

Please report privately through the contact details on
<https://www.jpps.us> rather than in a public issue.
